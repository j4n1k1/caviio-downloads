# Caviio downloads

Public release files for [caviio.com](https://caviio.com).

## VIRAL — Early Access Demo

The November 2, 2026 release provides a macOS VST3 installer and a source archive.
Download files from [Releases](https://github.com/j4n1k1/caviio-downloads/releases).

This is a development build. Features and behaviour may change. The PKG installer
is not signed with an Apple Developer ID; macOS may block installation. Keep
backups of important projects when testing early builds.

VIRAL is a modified version of the Vital synthesizer. The original source license
is GNU GPL version 3; see LICENSE. Third-party components retain their own notices
inside the source archive. Not affiliated with or endorsed by Vital Audio.

The source archive includes snapshot 472a367c4ae4d814b4c57b1d353cf6e275961b1b and
CLAP revision 27f20f81dec40b930d79ef429fd35dcc2d45db5b. See RELEASE-SNAPSHOT.txt
inside the archive for build-project locations. The private development repository
and its history are not published here.

SHA256SUMS.txt accompanies the release so downloaded files can be verified.
